# hackthenesttrack

Project repo for Hack The Nest, November 14–15, 2026 at Eastern Michigan University.

Final submission is Sunday, November 15, 12:00 PM ET. The submission needs this public repo, a short description, and a demo video of 3 minutes or less. Partner API keys stay out of git.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints. The page lists the open tracks so we can pick one and build in `src/`.

## Checks

```bash
npm run lint
npm run build
```

Resources: [hackthenest.tech](https://hackthenest.tech/), [Devpost](https://hack-the-nest.devpost.com/), [partner tools](https://hack-the-nest.devpost.com/resources).
